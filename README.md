# chemical\_database



\----------------------Chinese------------------

\# ChemDB 化学数据库

> 一个用于存储化学物质数据，方便程序检索、读取的本地化学数据库。



\## ✨ 项目简介

ChemDB 是使用 Python 开发的轻量级化学数据库。

\- 支持爬虫抓取化学相关信息

\- 使用 JSON 结构化存储化学物质数据

\- 支持打包为独立 EXE 文件，无需 Python 环境即可运行

\- 方便开发化学相关小工具、虚拟化学实验程序调用数据



\## 📦 功能清单

\- \[x] 化学物质信息爬虫采集

\- \[x] JSON 文件持久化存储

\- \[x] 数据查询接口

\- \[x] PyInstaller 打包成 EXE

\- \[ ] 批量导入化学数据（计划）



\##  快速开始

&#x20;------------  English  ------------------

\# ChemDB Chemical Database

> A local database for storing chemical substance data, allowing programs to retrieve and read information conveniently.



\## ✨ Project Introduction

ChemDB is a lightweight chemical database built with Python.

\- Crawl chemical information automatically

\- Store chemical data in structured JSON format

\- Support packaging into standalone EXE files. No Python environment needed for running

\- Suitable for developing chemistry utilities and virtual chemistry simulation programs



\## 📦 Features

\- \[x] Crawler for collecting chemical substance data

\- \[x] Persistent storage using JSON files

\- \[x] Data query interface

\- \[x] Package the program into EXE via PyInstaller

\- \[ ] Graphical user interface (In progress)

\- \[ ] Batch import of chemical data (Planned)



\## 🚀 Quick Start

\### Dependencies

Python >= 3.10
